## Sobre este repositorio

El código de mi portafolio: **[gabriel-curriculum.vercel.app](https://gabriel-curriculum.vercel.app)**

- Astro + Tailwind, 100 % estático, sin JavaScript de framework en el cliente
- Bilingüe (ES / EN) con rutas y anclas traducidas
- Tema claro / oscuro / sistema, con la preferencia guardada
- CV en HTML listo para imprimir o guardar como PDF en una sola página A4
- Contenido y textos centralizados en `src/data/portfolio.ts` y `src/i18n/ui.ts`

```bash
npm install
npm run dev      # servidor local en localhost:4321
npm run build    # astro check + build de producción en dist/
npm run preview  # revisar el build antes de desplegar
```

```
src/
├─ components/   secciones de la página e iconos SVG
├─ content/      certificados (markdown + PDF)
├─ data/         datos del portafolio en ES / EN
├─ i18n/         textos de interfaz y utilidades de idioma
├─ layouts/      layout base, tokens de color y estilos globales
└─ pages/        rutas: / · /cv · /en · /en/cv
```
